# Contributing

This repository is a systems-engineering study in concurrency, scheduling, memory behavior, and measurable performance.

## Development standards

- Keep performance-sensitive changes isolated and benchmarkable.
- Add tests for concurrency and correctness changes.
- Record meaningful benchmark methodology when reporting performance changes.
- Avoid optimizing without profiling evidence.

## Pull Requests

Describe the bottleneck, implementation change, validation performed, and observed impact on throughput, latency, CPU, or memory. Include benchmark details where relevant.
